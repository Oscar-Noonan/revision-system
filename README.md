# Revision System

## Description

This is my A-level OCR Computer Science NEA; a revision platform made to help students revise efficiently and effectively. The systems main features include a revision planner, retrieval based exam style questions and marking, and graphs displaying performance analytics.
> This project is uncompleted and still in development and will recieve regular updates.

## Installation and Usage

### Installation

If you would like to try my project you can clone it with:
```
git clone https://github.com/Oscar-Noonan/revision-system.git
```

### Usage

The project includes the `run.sh` shell script you can use to run the program from the project root:
```
./run.sh
```
Running the program only requires a python interpreter.
